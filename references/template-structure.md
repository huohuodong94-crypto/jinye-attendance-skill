# 考勤表标准模板结构说明

> 模板文件：`assets/attendance-template.xlsx`
> 输出必须严格继承模板的合并单元格、字体、边框、列宽、行高。

## 一、整体结构（3个工作表）

| 工作表 | 内容 | 行数 | 列数 |
|---|---|---|---|
| 考勤一览表 | 所有员工汇总，一行一人 | 30行 | 8列 |
| 陈江办公室 | 陈江办公室员工逐日打卡明细 | 316行 | 16列 |
| 公庄办公室 | 公庄办公室员工逐日打卡明细 | 158行 | 16列 |

## 二、考勤一览表结构

```
R1: 广东锦业体育设施有限公司（合并A1:H1，大标题，加粗居中）
R2: 2026年X月份考勤统计表（合并A2:H2，副标题）
R3: 表头：序号 | 部门 | 所属办公室 | 姓名 | 应上班天数 | 实上班天数 | 备注 | 签名
R4-R28: 员工数据（按办公室分组，公庄在前，陈江在后）
R30: 总经理核准：______ | 制表：______
```

### 字段格式

| 字段 | 格式 | 示例 |
|---|---|---|
| 应上班天数 | 数字 | `27` |
| 实上班天数 | 数字或"X天X小时" | `27`、`22天4小时`、`26天4小时` |
| 备注 | 异常说明文本 | `事假4天3.5小时`、`缺卡2次`、`非打卡考勤` |
| 签名 | 空（员工签字） | 空 |

### 注意事项
- 备注里"事假33.5小时"是**错误格式**，正确格式是"事假4天3.5小时"（天数+小时分开写）
- 非打卡考勤人员：应上班天数和实上班天数都填27，备注填"非打卡考勤"
- 离职人员：备注填离职日期（如`7.21离职`）

## 三、陈江办公室 / 公庄办公室结构

### 每个员工块固定占 26 行 × 16 列

左右分栏布局：
- **左栏（A-H列）**：1日-16日
- **右栏（I-P列）**：17日-31日

### 员工块内部行结构

| 行偏移 | 内容 |
|---|---|
| +0 | 单位、姓名、部门、日期范围、职位（合并单元格） |
| +1 | 工作天数：X  出勤天数：X  迟到次数：X  早退次数：X  缺卡次数：X  全勤：X  出差：X  外出：X  病假：X（完整9项统计） |
| +2 | 日薪工资：___  加班：___ |
| +3 | 上午 / 下午 / 加班（左右分栏子表头，合并单元格） |
| +4 | 日期 \| 星期 \| 上班(IN) \| 下班(OUT) \| 上班(IN) \| 下班(OUT) \| 上班(IN) \| 下班(OUT) |
| +5 ~ +20 | 打卡数据（16行，左栏1-16日，右栏17-31日） |
| +22 | 应出勤天数：27天 \| 实际出勤天数：___ \| 员工签字：___ |
| +23 | 考勤异常说明：___ |

### 每日打卡的8列含义

| 列（左/右） | 含义 |
|---|---|
| A / I | 日期（如`7.1`） |
| B / J | 星期（如`三`） |
| C / K | 上午上班(IN) |
| D / L | 上午下班(OUT) |
| E / M | 下午上班(IN) |
| F / N | 下午下班(OUT) |
| G / O | 加班上班(IN) — 用于填迟到/补卡/台风提前下班等标记 |
| H / P | 加班下班(OUT) |

## 四、打卡格子填充值规则

| 状态 | 填充方式 | 示例 |
|---|---|---|
| 正常打卡 | 填时间 | `08:30`、`12:05`、`18:00` |
| 周日休息 | 4个格子都填"休息" | `休息` |
| 事假全天 | 4个格子都填"事假" | `事假` |
| 调休假全天 | 4个格子都填"调休假" | `调休假` |
| 病假全天 | 4个格子都填"病假" | `病假` |
| 出差全天 | 有打卡的格全保留打卡时间（**黑色**），无打卡的格填"出差"（绿色），加班列标"出差" | `08:25`/`出差`/`出差`/`出差` |
| 外出全天 | 有上午打卡保留上午，下午显示"外出"（**橙**）；无打卡4格"外出"（橙） | `外出` |
| 半天请假 | 请假时段填请假类型，非请假时段填实际打卡 | 上午`事假`，下午`13:45`、`18:42` |
| 迟到 | 正常填打卡时间（标红），加班上班列填"迟到" | G列=`迟到` |
| 补卡 | 正常填打卡时间，加班上班列填"补卡"（蓝） | G列=`补卡` |
| 缺卡 | 描述含"X缺卡"→格内填"补卡"（蓝）；推断缺卡→留空 | 格内`补卡` |
| 台风提前下班 | 正常填打卡时间，加班上班列填"台风提前下班" | G列=`台风提前下班` |
| 离职 | 离职后第1天4格填"离职"（红），之后空白 | `离职` |

### 出差/外出日格值规则（模板实测）
- 覆盖时段内的打卡格填状态名（出差/外出），覆盖时段外填实际打卡时间
- 出差起始日/结束日早晨打卡：脚本显示实际时间（数据忠实）；模板部分显示"出差"（人工）
- 半天出差/外出：覆盖半天的格填状态名，未覆盖的填实际打卡时间

## 六、输出要求

1. 基于模板文件复制生成输出，**不重建格式**
2. 只修改数据单元格的值，保留所有合并单元格、字体、边框、颜色、列宽、行高
3. 颜色规则：迟到/早退标红、缺卡/补卡标蓝、出差/外出标绿、请假标紫
4. 考勤一览表的员工顺序：公庄办公室6人在前，陈江办公室在后
5. 非打卡考勤人员只出现在一览表，不生成详细打卡块
