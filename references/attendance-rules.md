# 锦业体育考勤计算规则（已确认）

> 本文档记录与客户（许凡）2026-09-02 会议确认的全部考勤计算规则，是考勤计算脚本的唯一规则依据。

## 一、基本制度

| 项目 | 规则 |
|---|---|
| 工作时间（5-9月） | 上午 08:30-12:00（3.5小时），下午 14:00-18:00（4小时） |
| 工作时间（10月-次年4月） | 上午 08:30-12:00（3.5小时），下午 13:30-17:30（4小时） |
| 工作制度 | 7、8月六天制（周日休息），其他月份双休日（周六日休息），国家法定节假日按带薪休假 |
| 每天标准工时 | 7.5小时 |
| 迟到标准 | 上午上班打卡晚于08:30；下午上班（第3次打卡）晚于规定时间（5-9月14:00，10-次年4月13:30） |
| 早退标准 | 下午下班打卡时间早于规定时间（5-9月18:00，10-次年4月17:30） |

## 二、打卡时间分类

- 每天最多4次打卡，按时间顺序分配：
  - 第1次 → 上午上班(IN)
  - 第2次 → 上午下班(OUT)
  - 第3次 → 下午上班(IN)
  - 第4次 → 下午下班(OUT)
- 打卡记录中可能带"外勤"标记（如`13:45外勤`），按正常打卡时间处理
- 超过4次打卡：取第1、2次为上午，最后1次为下午下班，第3次为下午上班（中间重复打卡忽略）

## 三、数据源优先级（v2 权威数据源）

### 3.0 权威数据源 = 月度考勤汇总 第26-56列（逐日考勤结果）

> 深度分析7月真实数据后确认：**月度考勤汇总第26-56列是逐日考勤结果列**（26=1日…54=31日），
> 单元格格式为 `状态说明\n(时间1,时间2,时间3,时间4)`，其中：
> - `-` 表示该次打卡缺卡
> - `None` 表示无数据
> - 状态说明含全量标记：`正常`、`休息`、`事假/病假/调休假XX小时`、`出差XX天`、`外出XX小时`、
>   `上班1迟到X分钟`、`下班2早退X分钟`、`下班1缺卡/上班2缺卡`、`补卡申请X到X`、`台风提前下班`等

**优先级**：考勤结果列 > 请假表（仅用于调休假类型修正）> 打卡/出差/外出表（兜底）。
因此脚本以考勤结果列为唯一主数据源，请假表仅用于判断"调休"事由→调休假，打卡/出差/外出表保留为参数但仅兜底。

### 3.1 出差
- 出差全天无打卡：4格全显示"出差"（绿色），加班列标"出差"
- **出差有打卡：有打卡的格全保留打卡时间（绿色），无打卡的格显示"出差"（绿色），加班列标"出差"**（v2修改：原规则仅保留第1个打卡时间）
- 半天出差：上午3.5小时 / 下午4小时
- 依据：以出差申请单的**出行人（创建人）**为准，每人自己的申请自己算，不通过"同行人"关联

### 3.2 外出
- 与出差工时规则一致（整天外出7.5小时，半天上午3.5h/下午4h）
- **外出颜色为橙色**（v2修改：原绿色）
- 有上午打卡：保留上午打卡时间，下午显示"外出"（橙色）
- 无打卡：4格全显示"外出"（橙色）
- 前提：有提交外出申请单

### 3.3 请假（带薪假分类）

| 请假类型 | 是否带薪 | 工时处理 |
|---|---|---|
| 婚假 | ✅ 带薪 | 计入出勤工时 |
| 产假 | ✅ 带薪 | 计入出勤工时 |
| 陪产假 | ✅ 带薪 | 计入出勤工时 |
| 法定节假日 | ✅ 带薪 | 计入出勤工时 |
| 事假 | ❌ 不带薪 | 不计入出勤工时 |
| 病假 | ❌ 不带薪 | 不计入出勤工时 |
| 调休假 | ❌ 不带薪 | 不计入出勤工时 |
| 其他假 | ❌ 不带薪 | 除非特别说明 |

- 全天请假：4个打卡格都填请假类型名称（如"事假""调休假"）
- 半天请假：请假时段填请假类型，非请假时段填实际打卡时间
- 请假类型根据"事由"字段判断：事由含"调休"→显示"调休假"，否则显示"事假"/"病假"

### 3.4 缺卡 / 补卡
- 每月 **3次补卡机会**
- 缺卡只记录次数，**不影响已有打卡时段的工时**
- 例：上午上班没打卡但下班打了 → 上午上班缺卡1次，下午工时正常算
- 未补卡的按缺卡记录，缺卡位置留空
- **补卡标记（v2修改）**：
  - 系统有申请补卡的，加班列标记"补卡X"（X为当月第几次补卡，如"补卡1""补卡2"）
  - 异常说明中写明"补卡X次"
  - 描述含"X缺卡"字样 → 对应格内填"补卡"（蓝色）

### 3.5 迟到/早退
- 只标记不额外扣工时（迟到/早退时间已自然反映在打卡时长中）
- **迟到（v2修改）**：
  - 上午上班打卡晚于08:30 → 标红，加班列填"迟到"
  - **下午上班（第3次打卡）晚于规定时间也算迟到**（5-9月晚于14:00，10-次年4月晚于13:30）
- 早退：下午下班打卡时间早于规定时间 → 标红

### 3.6 休息（周日）
- 4个打卡格都填"休息"
- 不计入出勤天数

### 3.7 整月出差（长期挂单）不按出差处理
- 出差申请"出差07-01到07-31"（整月跨度）视为长期挂单，**不作为出差**，按正常打卡计算
- 示例：马杨萍"出差07-01到07-31" → 正常打卡算工时（出勤27天）

### 3.8 外出优先于出差
- 同一标记串中"外出"通常是当天具体活动（如整月出差+当天外出），**外出优先**，按外出计算
- 多条出差记录同一天时合并时段（如崔怡30=出差到13:15+13:15起 → 全天出差）

### 3.9 台风（人工补充）
- 7.25台风：加班列填"台风提前下班"（罗玉珍/崔怡/彭宏/许凡/余唯/孙誉婕/翟海浩/杨建/郁魏）、
  "台风居家申请满勤"（谢铃铃）——用 SPECIAL_MARKERS 人工补充

### 3.10 离职
- 离职后第1天（离职日+1）明细块4格填"离职"（红色），之后空白
- 应出勤天数按整月工作日计（模板口径：离职员工应出勤仍显示整月，如李岭恩27天）
- 实际出勤只算离职前（李岭恩18天），一览表备注"7.21离职"

## 四、数据处理规则

### 4.1 重复记录去重
- 相同时间、相同类型、相同事由的重复申请只保留1条
- 依据：审批编号不同但内容完全一致的视为重复

### 4.2 跨月数据过滤
- 按统计月份过滤，非本月的申请记录不纳入计算
- 调休原则上不跨月，跨月需特别申请并说明

### 4.3 多段行程出差
- 一个出差申请可能有多段行程（多行），出行人只在第一行填写
- 处理：后续行程的出行人继承第一行的出行人
- 每段行程独立计算时间，合并为该员工的总出差时长

## 五、工时统计口径

- **按"天+小时"统计**，不是分钟
- 正常出勤按天算（如"27天"）
- 有半天异常按小时补充（如"22天4小时""事假4天3.5小时"）
- 备注格式示例：
  - `事假4天3.5小时`
  - `缺卡2次`
  - `驻福州申请整月出差`
  - `非打卡考勤`
  - `居家办公`
  - `7.21离职`

## 八、输出格式强制规则（防回归）

> 以下四项为8月跨月验证中发现的格式回归问题，已修复并写入规则。后续生成考勤表时必须严格遵守，不得再次出现。

### 8.1 日期行必须显示完整自然月范围

- 员工块顶部"日期："字段必须显示完整自然月范围：`日期：{year}.{month:02d}.01-{year}.{month:02d}.{days_in_month}`
- 示例（8月）：`日期：2026.08.01-2026.08.31`
- **禁止**只写开始日期不写结束日期（如`日期：2026.08.01-`）

### 8.2 台风等月度特殊标记不得硬编码

- `SPECIAL_MARKERS`（台风提前下班、台风居家申请满勤等）属于特定月份的独有特殊情况，**禁止硬编码在脚本中**
- 脚本中`SPECIAL_MARKERS`必须默认为空字典`{}`，仅在当月确有特殊情况时由使用者临时配置
- 生成其他月份考勤表时，输出中**不得出现**任何台风相关标记
- 原3.9节"台风"规则已废弃，7月25日台风为历史特例，不纳入通用规则

### 8.3 工作天数行必须输出完整统计字段

- 员工块第2行（`start_row + 1`）必须按模板完整格式输出全部9个统计字段：
  ```
  工作天数：{should_days}  出勤天数：{actual_str}  迟到次数：{late_count}  早退次数：{early_count}  缺卡次数：{miss_count}  全勤：{full_attendance}  出差：{travel_days}  外出：{outside_days}  病假：{sick_days}
  ```
- 字段说明：
  - 缺卡次数 = 缺卡次数（miss_count）
  - 全勤 = 1（无迟到、无早退、无缺卡、无请假），否则为0
  - 病假 = 病假类型请假天数
- **禁止**只输出"工作天数"和"出勤天数"两项而省略后续统计字段

### 8.4 sheet标题月份必须动态对应实际月份

- 三个sheet标题中的月份必须根据`--month`参数自动替换为实际月份：
  - 考勤一览表：`2026年{month}月份考勤统计表`
  - 陈江办公室：`广东锦业体育设施有限公司（{month}月）考勤明细`
  - 公庄办公室：`广东锦业体育设施有限公司（{month}月）考勤明细`
- 脚本加载模板后必须自动扫描前3行标题，将模板中的月份（如7月）正则替换为实际月份
- **禁止**输出中沿用模板的7月标题

### 8.5 清除打卡数据区时必须同时重置字体颜色

- `generate_detail_sheet`清除每个员工块的打卡数据区（`start_row+5`到`start_row+20`）时，必须同时将所有单元格的字体颜色重置为黑色（`FF000000`）
- 原因：模板中可能遗留7月的迟到红色、缺卡蓝色等颜色，`safe_write_cell`在`font=None`时只写值不修改字体，会导致模板颜色残留
- **禁止**只清除`cell.value`而不清除`cell.font`，否则正常打卡日会错误显示为红色/蓝色等

### 8.6 出差/外出日打卡时间必须为黑色

- 出差日：有打卡的格子填打卡时间（**黑色**），无打卡的格子填"出差"（绿色）
- 外出日：有打卡的格子填打卡时间（**黑色**），无打卡的格子填"外出"（橙色）
- 部分出差/外出日同理：实际打卡时间为黑色，仅"出差"/"外出"文字用对应颜色
- 参考7月模板：郁魏7.18出差日打卡时间`08:13/12:03/13:02`均为黑色，仅第4格"出差"为绿色
- **禁止**将出差/外出日的打卡时间标为绿色/橙色

### 8.7 请假段时长必须按段拆分标注

- 每段连续请假必须在**段首第一天**的加班列标注整段请假总时长（如"事假19.0小时""事假45.0小时"）
- 同一段请假的后续天**不重复标注**，仅4格填请假类型（紫色）
- 段首判断依据：当天请假描述（`leave_desc`）与前一天不同，则为新段首
- **请假段内的休息日（如周日）不断开请假段**：休息日显示"休息"，但`prev_leave_desc`不重置，休息日后的工作日仍属于同一段请假，不重复标注
- 全天请假和部分请假都必须标注段首时长（原规则仅部分请假标注，全天请假不标注，已修复）
- 示例（谢铃铃8月）：
  - 8.3-8.5 事假19小时 → 8.3加班列标"事假19.0小时"，8.4-8.5不标
  - 8.6-8.12 事假45小时（含8.9周日休息）→ 8.6加班列标"事假45.0小时"，8.7-8.8/8.10-8.12不标，8.9显示"休息"
  - 8.22 事假7.5小时 → 8.22加班列标"事假7.5小时"
- **禁止**整段请假只在某一天标注而其他段完全不标，或同一段请假重复标注多次

### 8.8 部分请假必须计算当天实际请假小时数

- **问题根因**：月度汇总每天的事假描述中都带**整段请假的总时长**（如8.3-8.5每天描述都是"事假08-03 13:57到08-05 18:00 **19小时**"）。如果直接把这个总时长赋给部分请假当天的`leave_hours`，会导致后续全天请假日被重复计算。
- **正确做法**：部分请假的`entry["leave_hours"]`必须计算**当天实际请假小时数**（与工作时间段的交集），使用`calc_daily_leave_hours()`函数。
- **整段总时长**（`leave_total_hours`）仅用于段首加班列标注（如"事假19.0小时"），不参与工时累加。
- **全天请假**的`leave_hours` = `STD_DAY_HOURS`（7.5小时），不受影响。
- **示例（谢铃铃8月）**：
  - 8.3部分请假（13:57开始）：当天请假≈4小时，`leave_hours=4`
  - 8.4全天请假：`leave_hours=7.5`
  - 8.5全天请假：`leave_hours=7.5`
  - 8.3-8.5段合计=4+7.5+7.5=19小时 ✓（与描述一致）
  - **错误做法**：8.3的`leave_hours=19`（整段总时长），则8.3-8.5合计=19+7.5+7.5=34小时，多算15小时（2天）
- **出差/外出无此问题**：出差和外出均按天计算（全天7.5小时），不涉及小时数累加，部分出差/部分外出也按全天7.5小时计工时（客户确认规则）。
- **禁止**将部分请假的`leave_hours`直接取描述中的整段总时长。

### 8.9 考勤异常说明格式与休息日特殊情况

- **异常说明固定顺序**：迟到X次 → 早退X次 → 缺卡X次 → 出差X天 → 外出X天 → 事假/病假X天X小时
- **只展示非零项**，为0的项不显示
- **补卡不再出现在异常说明中**（补卡序号已在明细加班列标注）
- **休息日（周日）有出差/外出必须计入**：`compute_attendance`中休息日不能直接`continue`，需先检查当天是否有出差/外出状态，有则计入`travel_days`/`outside_days`和`work_hours`，但不计入`should_days`（应出勤仍按工作日计）
- **缺卡次数 = 缺卡次数**，展示为"缺卡X次"
- 示例（崔怡8月）：8.30周日出差 + 8.31周一出差 = 出差2天（修复前只算1天）

### 8.10 加班列长文字必须自动换行

- 加班列（左栏G列=7，右栏O列=15）的文字（如"事假19.0小时""事假45.0小时""补卡1"等）必须设置`wrap_text=True`自动换行
- **禁止**文字溢出占用相邻的下班(OUT)列（H列/P列）
- 在`generate_detail_sheet`清除数据区时，统一设置加班列的`alignment = Alignment(wrap_text=True, vertical="center")`
- 其他列（打卡时间列）保持默认不换行

### 8.11 清除数据区必须取消所有合并单元格

- 模板中可能遗留合并单元格（如下班OUT列与加班IN列合并），导致写入的内容"占两个单元格"
- `generate_detail_sheet`清除数据区时，必须先扫描并取消数据区内（start_row+5到start_row+20，列1-16）所有合并单元格
- 取消合并后再清除值和重置字体颜色
- 示例（谢铃铃8.25）：模板遗留N44:O44合并，导致18:02显示为占两格；取消合并后18:02只在N列
- **禁止**在未取消合并的情况下直接写入数据
